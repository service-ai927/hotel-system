# Azure Coast PMS

リゾートホテル向け予約管理システム（PMS）のデモです。単一の `index.html` で動作し、ビルドやサーバーは不要です。

## 使い方

`index.html` をブラウザで開くだけで動きます。GitHub Pages でも公開できます。
操作内容はブラウザの localStorage に保存され、「設定 → デモデータをリセット」で初期状態に戻せます。

## 主な機能

| 画面 | 機能 |
|---|---|
| ダッシュボード | 稼働率・ADR・RevPAR、14日間の稼働予測、客室ステータス、到着・出発、操作履歴 |
| フロント | チェックイン（客室割当・宿泊者名簿・旅券確認・デポジット）、精算・チェックアウト、ウォークイン |
| 予約一覧 | 検索・絞り込み・並べ替え・ページ送り、CSVコピー、変更・延泊・キャンセル・ノーショー |
| 新規予約 | 日程 → 空室と料金 → ゲスト情報 → 確認の4ステップ、予約番号の発行 |
| 空室カレンダー | 客室×日付のタイムライン、ドラッグで客室移動・日程変更・未割当予約の割当 |
| 客室管理 | 客室ステータス、清掃状態、故障・使用停止 |
| ハウスキーピング | 清掃かんばん、担当の自動割当、連泊清掃の一括作成 |
| 顧客管理 | 宿泊履歴、累計利用額、VIP・要注意、好み・メモ |
| 料金・プラン | 料金カレンダー（日別個別料金）、プラン管理、販売停止、最低宿泊数 |
| チャネル管理 | OTAとの在庫・料金同期、新着予約の取込 |
| 請求・精算 | フォリオ、売上計上、入金登録、領収書 |
| レポート | 過去30日実績・今後30日予測、客室タイプ別・チャネル別・リードタイム・国別 |

料金は週末・繁忙期の係数、サービス料10%、消費税10%、宿泊税（1人1泊の料金に応じた段階制）を自動計算します。
サンプルデータは開いた日を基準に生成されるため、いつ開いても当日の業務画面として表示されます。

## 技術

- HTML / CSS / JavaScript（ライブラリ不使用）
- フォント: Google Fonts（Shippori Mincho, Zen Kaku Gothic New, IBM Plex Mono）
- ライト / ダークテーマ対応、スマートフォン表示対応
